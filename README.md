An economic model for organisations, built around contribution.

:exclamation: Please note, although this analysis outlines some initial suggestions it is still incomplete and in need of ongoing refinement. One of the decisions that needs to be made is the future path for Contributionism as a model. It could continue to focus on organisations and go into more detail or it could also becomes more broad and epochal like Capitalism, meaning it might be more useful to articulate principles for making broad system changes across many economic systems. Ultimately, fairly rewarding active contribution should be at the centre of any economy.
